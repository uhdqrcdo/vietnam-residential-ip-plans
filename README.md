## 先把四个词分清：机房IP、原生IP、住宅IP、双ISP

这四个词经常被混着用，实际说的是四件不同的事，而且可以叠加。

**机房IP**说的是IP的ASN归属在数据中心或云厂商名下。你查Whois，出来的是某个hosting服务商，不是电信运营商。这类IP的特征太统一了，平台的风控库早就把它们建成名单。

**原生IP**说的是IP的注册地和服务器实际所在地一致。一台机器放在胡志明市，IP却注册在新加坡，那叫广播IP，不叫原生。原生只解决“位置对不对”，不解决“像不像家庭用户”。

**住宅IP**再进一步：IP的归属机构是家庭宽带运营商，不是你租的那台服务器所在的机房。平台查IP时看到的是某个ISP的宽带段，company type 显示为ISP而不是hosting。

**双ISP**是这四层里最细的一层。按丽萨主机产品资料的描述，这个IP带有两个运营商的归属标记，IP的ASN归属和实际承载网络都来自家宽运营商。单ISP住宅IP已经比机房IP像人，双ISP是在“像人”这件事上再加一层。

关键点在这里：**平台查的是ASN归属和Whois记录，不是你在商品页上写了什么。** 商家说“住宅”不算数，得看第三方数据库怎么识别。所以后面我会专门讲怎么自己查。

## 买回来怎么自己验证IP属性

商家说住宅不算数，三个动作自己查一遍，十分钟搞定。

**第一步，ipinfo 或 ipregistry 查ASN。** 输入IP，看 `org` 或 `company.type` 字段。显示ISP或宽带运营商，说明归属对；显示hosting、cloud、datacenter，说明是机房段。这一步最关键，平台风控读的就是这类数据。

**第二步，Ping0 查IP类型。** 这类工具会直接给一个“住宅IP / 机房IP / 代理IP”的判断，和TikTok那类平台的检测逻辑接近。

**第三步，Whois 查归属机构。** 看注册机构是不是越南本地运营商，注册地是不是越南。这一步能同时验证“原生”和“住宅”两个属性：注册地在越南、机构是宽带运营商，两个条件都满足才算到位。

三项都过了，再接账号。有一项不对，48小时内申请退款，不用编理由。

## 几个需要提前知道的限制

**延迟不是大陆优化线路。** 三网184ms、联通270ms，这个水平不适合当远程桌面或低延迟建站机用。它的定位是IP属性，不是访问速度。

**年付版不能升级。** 配置固定，硬盘10GB、流量1TB，业务涨上来只能另开一台。

**IP纯净度是官方说法。** “全新IP段、没跑过其他业务”这类描述来自商家和推广方，第三方无法独立核验。你能做的是买回来用上面三个工具自己查一遍，用数据说话。
